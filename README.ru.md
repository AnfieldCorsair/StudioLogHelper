# StudioLogHelper - Pre-Release 1.1 (PyQt6)

Десктоп-приложение + CLI для парсинга, комфортного чтения, интеллектуального поиска и экспорта логов чатов **Google AI Studio** (JSON-файлы с Google Drive, в том числе скачанные **без расширения**), текстовых логов **Arena AI** и очищенных TXT/MD экспортов.

---

## Ключевые возможности

### 📖 Режим «Книга» (Book Mode) и Типографика
- **Удобное чтение:** Превращает диалоги в структурированную книгу с аккуратной вёрсткой, блоками реплик и адаптивной шириной колонки (`740px`, `920px`, `100%`).
- **Специальные палитры:**
  - 📜 **Тёплая бумага (Solarized Warm):** мягкий фон `#fdf6e3`, комфортный контраст `#43525a`, акцент `#b58900`.
  - 🕰 **Винтажная сепия:** фон `#f4ecd8`, тёплый текст `#3c2f1f`.
  - 🌙 **Ночное чтение (Soft OLED):** мягкая ночная гамма `#191a21`, текст `#d0d3dc`.
  - ☀️ **Светлая** и 🌑 **Тёмная** темы.
- **Типографика:** гарнитуры Serif (`Georgia`, `Noto Serif`, `Merriweather`), Sans-serif, Monospace; регулировка интерлиньяжа (`1.4x`, `1.7x`, `2.0x`) и масштаба шрифта `A−` / `A+`.
- **Быстрая навигация:** переход по репликам `Ctrl+↑` / `Ctrl+↓`, оглавление (TOC) с превью и бейджами ролей.

### 🖍 Интерактивные цитаты и маркеры (Highlighter)
- Выделение фрагментов текста мышью и окрашивание маркером: 🟡 **Жёлтый**, 🟢 **Зелёный**, 🌸 **Розовый**, 🔵 **Голубой**.
- Точные границы цитат `(start, end)` и хэш источника для защиты от сдвига позиций.
- Добавление пользовательских заметок к цитатам и закладкам (`Ctrl+B`).
- Сохранение цитат в проекте `.slh.json` и экспорт готового Markdown-дайджеста со всеми выжимками.

### 🔎 Нечёткий и гибридный поиск (FTS5 + Стемминг + Символьные N-граммы)
- **Лексический поиск:** мгновенный поиск через SQLite FTS5 (BM25) по проиндексированным папкам.
- **Морфологический стемминг (RU/EN):** алгоритм Портера находит все формы слова (поиск `«сковородка»` находит `«сковорода»`, `«сковороду»`, `«сковороде»`).
- **Локальные n-граммы:** ранжирование с устойчивостью к опечаткам без необходимости скачивания тяжёлых нейросетей.
- **Асинхронный SearchWorker:** неблокирующий фоновый поиск с отменой устаревших запросов и debounce (350 мс) при вводе.
- Поддержка точных фраз в кавычках (`"точная фраза"`) и префиксов (`термин*`).

### 🗃 Проекты, Иерархические категории и Неблокирующее автосохранение
- **Иерархические категории:** поддержка вложенных структур вида `Work/Research/Gemini`, `Work/Code`, `Personal/Ideas` с фильтрацией поддеревьев.
- **Атомарное фоновое автосохранение (`SaveProjectWorker`):** неблокирующая запись изменений проекта `.slh.json` в фоновом потоке через временный файл и `fsync` с созданием резервной копии `.bak`.
- **Переносимость проектов:** относительные пути `rel_path` позволяют открывать проекты на других компьютерах без потери файлов.
- **История изменений:** поддержка многоуровневого Undo/Redo (`Ctrl+Z` / `Ctrl+Y`).

### 🛡 Безопасность и Плагины
- **Санитизация HTML:** встроенная защита от XSS, опасных протоколов `javascript:` и небезопасных тегов.
- **Безопасные внешние ссылки:** автоматическое добавление `rel="noopener noreferrer"`.
- **Safe Mode для плагинов:** флаг `--safe-mode` / `--disable-plugins` в CLI и GUI для блокировки исполнения стороннего кода при аварийном запуске. Экспериментальные парсеры других форматов вынесены в плагины.

## Запуск и установка

```bash
pip install -r requirements.txt
python app.py
# или
python -m studiologhelper.ui.app
```

Установка как консольный пакет:

```bash
pip install .
studiologhelper
# или CLI
slh --help
```

### CLI команды:

```bash
python cli.py export path/to/log -f txt -o out/
python cli.py index path/to/folder
python cli.py search "сковородка"
```

## Горячие клавиши

- `Ctrl+O` — Открыть файлы
- `Ctrl+Shift+O` — Открыть папку
- `Ctrl+E` — Экспорт текущего чата
- `Ctrl+Shift+E` — Экспорт всех чатов
- `Ctrl+B` — Закладка / Цитата
- `Ctrl+F` — Поиск в тексте
- `Ctrl+K` — Быстрый поиск в открытых чатах
- `Ctrl+1..5` — Переключение вкладок (Карточки, Виртуализация, Книга, Исходник, Поиск)
- `Ctrl+↑` / `Ctrl+↓` — Предыдущий / следующий блок в книге
- `Ctrl+=` / `Ctrl+-` / `Ctrl+0` — Масштаб шрифта
- `Ctrl+Z` / `Ctrl+Y` — Отмена / Повтор действия
